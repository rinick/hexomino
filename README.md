# Hexomino Studio · 拼图实验室

本地网页，用现有 37 个拼块求解 **12×18 平面拼图**和 **6×6×6 立体堆叠**。

## 启动

需要 Node.js 20 或更新版本。首次运行：

```bash
npm install
npm start
```

打开 <http://127.0.0.1:5173>。再次启动只需 `npm start`；用 `Ctrl+C` 停止。
端口被占用时可运行 `PORT=5174 npm start`。安装后所有资源均在本地，无需联网。
不要直接双击 `index.html`，浏览器需要 HTTP 服务加载模块、STL 和后台求解器。

## 使用

- 左侧选择或拖放拼块；也可输入整数 X、Y、Z 坐标，点击「放置并固定」。坐标从 0 开始，X 向右、Y 向上、Z 为高度。
- 平面模式：旋转 90°、翻面；立体模式：绕 X/Y/Z 轴旋转 90°。立体拼块只使用真实旋转，不生成无法实现的三维镜像。
- 手动放置默认固定位置和朝向。点击拼块可移动、旋转、取消固定或移除。
- 「求解时仅允许当前朝向」可单独约束某块的朝向，同时让求解器自由选择位置。
- 点击「开始求解」时，仅保留固定拼块，再搜索其余拼块。「固定全部」「仅保留固定」可用来调整一个解后继续搜索。
- 两种模式、拼块库和选中预览均直接加载 `STL_37/` 的真实镂空模型。平面模式使用正交俯视相机，保留真实开孔与圆角；立体模式支持转动视角、拖放、选择 Z 放置层、分层编辑、剖切及分解视图。分解状态下先收起分解视图再拖动模型。剖切、分解只影响显示。
- 「示例解」载入经验证的完整排布，不添加固定条件；可以选几块固定，再求解剩余部分。
- 「保存排布」导出 JSON，包含位置、朝向和约束；「导入排布」恢复。两种模式分别自动保存在当前浏览器中，清空和编辑均可撤销。
- 快捷键：`R` 绕 Z 旋转，平面 `F` 翻面，`Delete` 移除，`Ctrl/⌘+Z` 撤销。小屏幕也可通过选择拼块、点击格子及坐标输入操作。

## 求解含义

每种拼块恰好用一次，覆盖 216 个完整单位格，不重叠、不越界。默认允许平面翻面；三维允许最多 24 种刚体旋转，拼块仍保持单格厚度的平面形状。

求解器采用精确覆盖 Algorithm X / Dancing Links，并检查剩余连通区域和黑白格数量。Web Worker 在后台搜索，不阻塞编辑界面。穷尽搜索才能报告「无解」；超时或手动停止都表示**尚未确定**，可延长搜索。求解时间会随条件和设备变化，不保证任意条件都能快速判定。

求解使用 `shapes.json` 的单位格占用，显示使用原始 STL。它不利用孔洞交错插入，也不验证重力支撑、碰撞插入路径或实际装配顺序。CAD 尺寸和设计规范仍以 `Hexomino_V6.md` 为准。

## 文件与验证

- `index.html`、`web/`：界面、STL 查看器及求解器。
- `server.mjs`：仅监听本机的静态服务。
- `examples/`：两种模式的完整解，可从网页载入。
- `shapes.json`、`STL_37/`：直接复用原有数据与模型。

运行 `npm test` 检查完整求解、固定条件续算、无解证明、超时区分、输入合法性和 STL 旋转后的尺寸。网页只计算最终排布，不改写 CAD 文件。
